## 公開の手順
1. 本人が「本番OK」→ staging を main にまとめて twistrush.com を最新にする
   - 本番（twistrush.com）に合言葉 TESTER_PASS が入っていたら外す（審査の人が入れなくなるため）。https://twistrush.com/__gate_status が「gate: off」ならOK
2. pwabuilder.com で https://twistrush.com を入れる → Package For Stores → Android → Google Play
   - Options で、パッケージ名・アプリ名・開始URL・色・版を上の値にする。通知（Notification delegation）はオン
   - 署名キーは「新しく作る」。会社名などを入れて作成し、zipをダウンロードする
   - zipの中の signing.keystore と signing-key-info.txt は、なくすと二度とアップデートできない。Dropboxの非公開フォルダなど安全な場所に保管する（Claudeには送らない）
3. Play Console → アプリを作成（名前 TWIST RUSH、言語 日本語、ゲーム、無料）
4. 「アプリのコンテンツ」を上の回答どおりに埋める。ストアの掲載情報に文と画像を入れる
5. 本番 → リリースを作成 → zipの中の .aab をアップロード（Play アプリ署名を使う）→ 国は日本 → 審査に送る
6. Play Console →「アプリの完全性」→「アプリの署名」にある2つの SHA-256 フィンガープリント（アプリ署名鍵・アップロード鍵）をClaudeに渡す。公開情報なので送ってよい。Claudeが src/worker.js の ASSETLINKS に入れる（/.well-known/assetlinks.json で返す）。入れないとアプリの上にアドレスバーが出る
7. 新しいアプリの審査は数日〜1週間ほどかかることがある
